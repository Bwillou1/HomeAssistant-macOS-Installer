Home Assistant Desktop for macOS

✨ Installation automatique sans configuration
🚀 Lancement au démarrage de macOS
🔐 Gestion intelligente des permissions
🌐 Interface web accessible sur localhost:8123
📱 Compatible Intel et Apple Silicon
📋 Ce qui sera installé :
• Binaire Home Assistant dans /usr/local/bin/
• Service système LaunchDaemon
• Configuration par défaut
• Scripts de gestion
⚠️ Important :
Cette installation nécessite des privilèges administratifs pour configurer le service système. L'assistant vous demandera votre mot de passe macOS.
