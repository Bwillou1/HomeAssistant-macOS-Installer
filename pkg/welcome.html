Home Assistant Core

Self-contained, local-first home automation runtime for macOS

This package installs Home Assistant Core as a dedicated system background service managed by launchd. All dependencies are bundled into an isolated, relocatable runtime without altering your system Python environment.

Installation Layout
Application Path /opt/homeassistant Configuration /Library/Application Support/HomeAssistant System Service launchd (unprivileged _homeassistant account) Web Interface http://localhost:8123
Administrator privileges required: macOS will prompt for credentials to configure the dedicated system account and register launch daemons.
